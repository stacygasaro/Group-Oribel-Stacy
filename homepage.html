What is Software Development?

Software development is the process of designing, writing, testing and maintaining programs.

Steps of the development process

  1. Gather requirements
  2. Design the solution
  3. Write the code
  4. Test the program
  5. Deploy and maintain

Popular programming languages

  • HTML (structure of web pages)
  • CSS (style of web pages)
  • JavaScript (behavior of web pages)
  • Python
  • Java
